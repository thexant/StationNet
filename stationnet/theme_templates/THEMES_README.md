# StationNet colour themes

Copy `template-theme.json`, then edit `id`, `name`, `author`, and the colours.
The `id` uses lowercase letters, digits, and hyphens. Each colour is a six-digit
hex value (`#RRGGBB`). Keep all fields within a section, but omit the entire
`site` or `masthead` section if your theme only changes one of them.

On a station, the template is copied to `<STATIONNET_DATA>/themes/`. You can
import your edited JSON file in SYSOP Settings, or place it in that directory
as `<id>.json`. The template itself is never offered as a selectable theme.
Custom themes are stored on each station and are available to its members.
An imported ID must be unique on that station.
