Windows

Download the Windows ZIP, extract it, then run install.bat. Start from the created StationNet shortcut or start.bat. The offline package includes its runtime.

Linux & Raspberry Pi

Use a ZIP built for the same OS, CPU, and Python 3.11+ ABI. Extract it, run sh install.sh, then ~/.local/share/stationnet/start.sh. No network is needed after download.

Android

On a 64-bit ARM Android 8+ device, install the APK, open it, and tap Start station. Complete setup in the local browser screen; nearby devices can join the same Wi-Fi or hotspot.

Where to host

Personal: use 127.0.0.1. LAN: allow TCP 8080 through the host firewall and share the host’s LAN URL. Public: use an HTTPS reverse proxy and a trusted certificate; do not expose plain HTTP logins publicly.
